The process

Four steps, without leaving the keyboard

The same process for every detection type — only the final action differs.

01

Copy

Any text — phone, tracking number, address, link, or just plain text.

02

Detect

The right detector wins (phone/tracking/address/link), and normalizes the value.

03

Popup opens

For phone — a message template with a name. For the rest — a ready action button.

04

Click, done

WhatsApp / Maps / tracking site / the link opens — one click and that's it.

What's detected

Four built-in detectors, plus your own custom rules

All active by default in the desktop agent, each can be turned off individually. The browser extension currently detects phone numbers only. A copied number with a non-Israeli + country code now also opens WhatsApp instead of being ignored.

Capabilities

What's inside

🔍

Number detection & normalization

Mobile and landline, with or without a dash, +972 or a leading zero — output is always normalized to the format WhatsApp requires.

✍️

Templates by lead type

5 default templates — new lead, follow-up, reminder, and more — fully editable, with a dynamic {name} token.

🔁

Duplicate-send alert

"A message was already sent to this number 6 min ago" — not blocking, just a reminder before an accidental double send.

📋

WhatsApp send history + CSV

Last 25 sends, local only. One-click export to Excel, in an encoding that supports Hebrew.

🕑

Clipboard history (Win+V), on the agent

Every copy is logged — not just what was detected. Search, filter by category, and paste back with one click. Open with Ctrl+Alt+V.

⌨️

Open manually, anytime

Even without a number on the clipboard — a keyboard shortcut opens the popup with a manual entry field.

🔒

Everything local

No external server. The only outbound action is opening a link (WhatsApp/Maps/Waze/tracking) in the browser — including sensitive copies (passwords), which are automatically skipped from history.

  • International phone fallback: a copied number with an explicit non-Israeli + country code now opens WhatsApp too, instead of being silently ignored. Israeli-number detection is unchanged.
  • Tray "Recent actions" submenu: the last 5 actionable copies, one click to re-fire the action without reopening the full history panel.
v2.0.0 2026-09-13

Renamed — PingClip became ActionClip, new visual identity

  • Full rebrand: code, installer files, icon (replacing the WhatsApp symbol, which no longer reflected a product with multiple destinations), and a new brand gradient — indigo-purple instead of green-teal, across all four app windows and this page.
  • Past data (templates/settings/history) doesn't migrate automatically — the local data file was renamed along with the product.
v1.4.1 2026-09-13 Root-cause fix

Desktop agent — clipboard detection silently broken since 1.3.1

  • Root cause found: Electron 44 made clipboard.readText() Promise-based; the code called it as if synchronous, so every check actually got a Promise object instead of a string — 1.3.1 "fixed" this in a way that stopped the crash, but made detection fail completely and silently.
  • Fixed with a real await on every clipboard call, and verified directly on the same Electron version + a real install on the machine.
v1.4.0 2026-09-13

Full clipboard history (Win+V) fix

  • New copy-history panel — every copied text is logged, not just what was detected. Search, filter by category, paste back.
  • Fixed: Israel Post tracking numbers (9 digits) were being swallowed by landline phone detection since 1.3.0 — detector check order is now reversed (general before phone).
v1.3.1 2026-09-11

Crash fix (partial — the full diagnosis came only in 1.4.1)

  • Non-string input from the clipboard caused a repeating error dialog every 800ms. Stopped, but the root cause (the Promise API) was only correctly diagnosed later.

Installation

Getting started

Choose one component or both — each stands on its own. Full guide + troubleshooting: README.md.

🧩 Chrome extension

chrome-extension/
  1. In Chrome, open chrome://extensions
  2. Enable Developer mode (top right)
  3. Click Load unpacked, and select the folder
  4. Pin the ActionClip icon to the toolbar

About 30 seconds, once per device. Updating: same steps, or click refresh on the extension card.

🖥️ Desktop agent

ActionClip-Setup-2.8.0.exe
  1. Run the Setup file (admin rights required — the agent installs per-machine)
  2. Go through the standard Windows wizard steps
  3. The agent launches automatically — icon in the system tray

Windows may show a SmartScreen warning for unsigned internal software — click "More info" → "Run anyway". After this first install, future updates download and install themselves automatically — see "Automatic updates" below.

Automatic updates

Stays current on its own

From v2.5.6 onward, the desktop agent checks GitHub Releases for a newer build a few seconds after it starts — no manual re-download for routine updates.

🔄 Background check

A few seconds after launch, ActionClip quietly checks for a newer release — no delay to startup, no prompt if there's nothing new.

⬇️ Auto-download + confirm

If an update exists, it downloads in the background, then a small dialog offers "Restart Now" or "Later" — pick Later and it installs automatically on the next normal quit.

🔌 Fails quietly offline

No connection or GitHub unreachable? The check fails silently and is logged to the local log file — the agent keeps working normally either way.

FAQ

Before you install

Is my data sent to the cloud?

No. There's no ActionClip server at all — no analytics, no telemetry, no AI calls. The only thing that leaves the device is opening a wa.me link in the browser, exactly like typing the URL yourself. Full details: PRIVACY.md.

Do I need administrator rights?

Not required — the installer automatically falls back to a per-user install under %LOCALAPPDATA% if there are no admin rights. The Chrome extension needs no permissions beyond Chrome's standard extension-load confirmation.

Where are templates and history stored?

Locally only: the agent stores data in %APPDATA%\ActionClip; the extension stores data in chrome.storage (synced through your own Google account, not an ActionClip account).

What happens if I close the agent window?

The agent keeps running in the background (system tray icon) to detect copies — the X doesn't quit the app. To actually quit: right-click the tray icon → Exit.

🖥️ סוכן שולחן עבודה

ActionClip-Setup-2.8.0.exe
  1. מריצים את קובץ ה-Setup (נדרשות הרשאות מנהל — ההתקנה היא ברמת המחשב)
  2. עוברים את שלבי האשף הרגילים של Windows
  3. הסוכן עולה אוטומטית — אייקון במגש המערכת

Windows עשוי להציג אזהרת SmartScreen לתוכנה פנימית לא חתומה — "More info" ← "Run anyway". אחרי ההתקנה הראשונית, עדכונים עתידיים יורדים ומתקינים את עצמם אוטומטית — ראו "עדכונים אוטומטיים" למטה.

שאלות נפוצות

לפני שמתקינים

האם המידע שלי נשלח לענן?

לא. אין שרת של ActionClip בכלל — לא analytics, לא telemetry, לא קריאת AI. הפעולה היחידה שיוצאת מהמכשיר היא פתיחת קישור wa.me בדפדפן, בדיוק כמו הקלדת ה-URL בעצמך. פירוט מלא: PRIVACY.md.

האם צריך הרשאות מנהל (Admin)?

לא חובה — המתקין נופל אוטומטית להתקנה per-user ב-%LOCALAPPDATA% אם אין הרשאות. תוסף ה-Chrome לא דורש הרשאות כלל מעבר לאישור הרגיל של Chrome בטעינת תוסף.

איפה נשמרות התבניות וההיסטוריה?

מקומית בלבד: הסוכן שומר ב-%APPDATA%\ActionClip; התוסף שומר ב-chrome.storage (מסונכרן דרך חשבון Google שלך, לא חשבון ActionClip).

מה קורה אם סוגרים את חלון הסוכן?

הסוכן ממשיך לרוץ ברקע (אייקון במגש המערכת) כדי לזהות העתקות — X לא יוצא מהתוכנה. יציאה אמיתית: קליק ימני על אייקון המגש ← יציאה.
